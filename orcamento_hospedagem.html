Justificativa

Escolhemos o GitHub Pages porque o site é estático (HTML, CSS e JavaScript), o custo é zero, o HTTPS é automático e a publicação acontece a cada push no mesmo repositório exigido pela disciplina. Assim, o código e o site online ficam sempre sincronizados.

A limitação é não haver servidor para receber formulários; por isso o formulário valida os dados e prepara a mensagem no próprio navegador. Netlify e Vercel foram descartados por não trazerem vantagem para este escopo: a Vercel limita o plano gratuito a uso não comercial e o Netlify oferece formulários, recurso que podemos adotar numa evolução do projeto.
